# NFR-003: NuGet .NET Tool packaging

**Specification status:** Proposed
**Priority:** Must
**Source:** [Nonfunctional requirements](../../requirements/non-functional.md)

## Purpose

Package as Infoconex.DotNetFramework.Tools with dotnet-framework command and help/version behavior.

## Boundaries

Verify this quality obligation only on the platforms and build artifacts actually tested.

## Acceptance scenarios

### NFR-003-SC01: Package command identity

**Given** Given the packaged .NET Tool,
**When** When installed via the .NET CLI,
**Then** Then its command can be invoked as dotnet-framework and as dotnet framework.

### NFR-003-SC02: Help and version exit successfully

**Given** Given an installed CLI package,
**When** When --help and --version are invoked,
**Then** Then each produces clear output with successful exit status.
