# NFR-003: Safe inspection of untrusted metadata

[Nonfunctional requirements](../../requirements/non-functional.md) · [Verification evidence](../../testing/traceability.md)

## Quality obligation

Candidate binaries are untrusted data and must never be loaded for execution; corrupt metadata must not bypass parser safety limits.

## Acceptance scenarios

### NFR-003-SC01: Do not execute inspected code

**Given** a synthetic assembly contains a module initializer with an observable side effect

**When** the metadata reader inspects that file

**Then** the side effect does not occur and no inspected assembly code is executed.

### NFR-003-SC02: Contain adversarial binary metadata

**Given** a synthetic binary contains invalid or adversarial PE metadata offsets and lengths

**When** the adapter inspects it under configured resource bounds

**Then** processing returns a classified error within the documented budget, without an unsafe read or uncaught crash.
