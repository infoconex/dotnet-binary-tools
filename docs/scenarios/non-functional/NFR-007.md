# NFR-007: Bounded resource consumption

**Specification status:** Proposed
**Priority:** Must
**Source:** [Nonfunctional requirements](../../requirements/non-functional.md)

## Purpose

Avoid unbounded binary processing and directory traversal; define measurable budgets before release.

## Boundaries

Verify this quality obligation only on the platforms and build artifacts actually tested.

## Acceptance scenarios

### NFR-007-SC01: Reject oversized or malformed input safely

**Given** Given a synthetic PE with malformed lengths or over-limit metadata,
**When** When it is inspected,
**Then** Then the tool produces a bounded failure without crashing or consuming unbounded memory.

### NFR-007-SC02: Scan limits remain effective

**Given** Given a directory tree exceeding an agreed file/depth budget,
**When** When a bounded scan runs,
**Then** Then the tool terminates predictably with an actionable limit outcome.

## Verification notes

Use synthetic, non-sensitive fixtures and [the testing strategy](../../testing/strategy.md). Record observed scenario-to-test evidence in [traceability](../../testing/traceability.md); this document does not claim passing tests.
