# NFR-004: Automated acceptance and evidence

**Specification status:** Proposed
**Priority:** Must
**Source:** [Nonfunctional requirements](../../requirements/non-functional.md)

## Purpose

NUnit tests, fixture provenance, cross-platform CI and scenario-level observed traceability.

## Boundaries

Verify this quality obligation only on the platforms and build artifacts actually tested.

## Acceptance scenarios

### NFR-004-SC01: Requirement scenario coverage

**Given** Given an in-scope implemented scenario,
**When** When its PR is reviewed,
**Then** Then a mapped test or documented manual check and observed evidence are available.

### NFR-004-SC02: CI results are observable

**Given** Given a candidate commit,
**When** When CI completes,
**Then** Then the exact SHA, operating system, execution result and failure information are recorded and traceability is updated.

## Verification notes

Use synthetic, non-sensitive fixtures and [the testing strategy](../../testing/strategy.md). Record observed scenario-to-test evidence in [traceability](../../testing/traceability.md); this document does not claim passing tests.
