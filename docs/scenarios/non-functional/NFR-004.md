# NFR-004: Bounded resource consumption

**Specification status:** Proposed — not approved or implemented

[Nonfunctional requirements](../../requirements/non-functional.md)

## Quality obligation

Resource controls constrain candidate parsing and directory inventory and produce explicit incompleteness rather than uncontrolled consumption.

## Acceptance scenarios

### NFR-004-SC01: Bound parsing of oversized candidates

**Given** a synthetic candidate exceeds the configured processing budget

**When** an inspection attempts to parse that candidate

**Then** processing stops within the budget and emits the appropriate limit reason without unbounded CPU or memory use.

### NFR-004-SC02: Bound recursive inventory

**Given** a synthetic directory tree exceeds the configured file-count or depth budget

**When** a valid bounded scan executes

**Then** the scan terminates predictably and reports the limit, incomplete coverage and all completed findings.
