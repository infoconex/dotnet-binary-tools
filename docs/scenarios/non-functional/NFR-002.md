# NFR-002: Cross-platform support

**Specification status:** Proposed
**Priority:** Must
**Source:** [Nonfunctional requirements](../../requirements/non-functional.md)

## Purpose

Equivalent metadata interpretation on supported Windows, Linux and macOS.

## Boundaries

Verify this quality obligation only on the platforms and build artifacts actually tested.

## Acceptance scenarios

### NFR-002-SC01: Cross-platform fixture consistency

**Given** Given the same managed assembly fixtures on Windows, Linux and macOS,
**When** When metadata inspection is executed,
**Then** Then equivalent targets and classifications are reported.

### NFR-002-SC02: Independent of inspected runtime

**Given** Given a managed .NET Framework 4.8 DLL on a supported host lacking .NET Framework,
**When** When its target metadata is inspected,
**Then** Then inspection does not require installing that runtime.

## Verification notes

Use synthetic, non-sensitive fixtures and [the testing strategy](../../testing/strategy.md). Record observed scenario-to-test evidence in [traceability](../../testing/traceability.md); this document does not claim passing tests.
