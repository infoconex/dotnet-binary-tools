# NFR-002: Cross-platform interpretation consistency

[Nonfunctional requirements](../../requirements/non-functional.md) · [Verification evidence](../../testing/traceability.md)

## Quality obligation

Equivalent binary metadata must yield equivalent declared-target facts and classifications on Windows, Linux and macOS x64.

## Acceptance scenarios

### NFR-002-SC01: Interpret the same fixtures consistently

**Given** identical managed, native and unknown-target fixtures exist on each supported x64 host

**When** those fixtures are inspected on Windows, Linux and macOS

**Then** managed classification and declared-target facts agree across hosts, apart from explicitly documented host-dependent file path information.

### NFR-002-SC02: Avoid target-runtime prerequisites

**Given** a supported host lacks the .NET Framework version declared by a managed test fixture

**When** the fixture is inspected statically

**Then** its declaration is read without installing or executing the inspected target runtime.
