# NFR-001: Resilient error handling

**Specification status:** Proposed
**Priority:** Must
**Source:** [Nonfunctional requirements](../../requirements/non-functional.md)

## Purpose

Actionable, isolated file errors; directory scan continues after malformed or inaccessible inputs.

## Boundaries

Verify this quality obligation only on the platforms and build artifacts actually tested.

## Acceptance scenarios

### NFR-001-SC01: Single unreadable file yields useful failure

**Given** Given a file inaccessible to the current process,
**When** When it is inspected,
**Then** Then a classified error and nonzero command outcome are produced without a stack trace dump.

### NFR-001-SC02: Directory scan isolates failures

**Given** Given an unreadable file beside readable managed assemblies,
**When** When scan is executed,
**Then** Then remaining files are processed and the failed file is recorded separately.
