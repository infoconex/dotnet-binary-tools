# NFR-001: Resilient and diagnostic-safe error handling

[Nonfunctional requirements](../../requirements/non-functional.md) · [Verification evidence](../../testing/traceability.md)

## Quality obligation

Operational failures shall remain bounded and actionable without disclosing file contents, sensitive data or unhandled exception stacks.

## Acceptance scenarios

### NFR-001-SC01: Handle a file read failure safely

**Given** a file becomes unreadable after a valid request passes input validation

**When** inspection attempts to read the file

**Then** a classified I/O issue identifies the affected input, with no unhandled stack trace or file content disclosure.

### NFR-001-SC02: Contain individual scan failures

**Given** a valid directory contains readable candidates and a candidate that fails during reading

**When** the scan executes

**Then** readable results remain available, the failed candidate is recorded, and unrelated findings are not discarded.
