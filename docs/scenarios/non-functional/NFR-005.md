# NFR-005: Safe metadata-only inspection

**Specification status:** Proposed
**Priority:** Must
**Original README reference:** New
**Source:** [Nonfunctional requirements](../../requirements/non-functional.md)

## Purpose

Candidate assembly code is never dynamically loaded or executed during inspection.

## Boundaries

Verify this quality obligation only on the platforms and build artifacts actually tested.

## Acceptance scenarios

### NFR-005-SC01: Never execute untrusted assembly code

**Given** Given a managed assembly containing a side-effecting module initializer,
**When** When its target is inspected,
**Then** Then the initializer does not execute and no target code runs.

### NFR-005-SC02: Do not use load-based inspection

**Given** Given a representative instrumented inspection execution,
**When** When the metadata reader processes the assembly,
**Then** Then candidate binaries are never passed to Assembly.Load, LoadFrom or equivalent execution-capable loading APIs.
