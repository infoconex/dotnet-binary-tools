# NFR-006: Runtime-free Native AOT distribution

**Specification status:** Proposed
**Priority:** Must
**Source:** [Nonfunctional requirements](../../requirements/non-functional.md)

## Purpose

Distribute .NET 11 Native AOT executables and RID-specific tool packages that run without .NET 11 installed.

## Boundaries

Verify this quality obligation only on the platforms and build artifacts actually tested.

## Acceptance scenarios

### NFR-006-SC01: AOT runs without the runtime

**Given** Given a supported published Native AOT binary on a clean host without .NET 11 installed,
**When** When it is executed with --help and a fixture inspection,
**Then** Then both operations succeed without installing .NET.

### NFR-006-SC02: Tool package selects supported RID

**Given** Given a published RID-specific .NET Tool and a clean supported system,
**When** When dotnet tool install selects the native package,
**Then** Then the installed executable runs and produces the expected output.

## Verification notes

Use synthetic, non-sensitive fixtures and [the testing strategy](../../testing/strategy.md). Record observed scenario-to-test evidence in [traceability](../../testing/traceability.md); this document does not claim passing tests.
