# FR-004: Recognize framework families

**Specification status:** Proposed
**Priority:** Must
**Source:** [Functional requirements](../../requirements/functional.md)

## Purpose

Recognize .NET Framework, .NET Standard and modern .NETCoreApp without fixed upper version limits.

## Boundaries

This requirement does not authorize implementing dependent features early. Keep the declared framework distinct from SDK and executing runtime identity.

## Acceptance scenarios

### FR-004-SC01: Recognize known families

**Given** Given samples with .NETFramework, .NETStandard and .NETCoreApp target monikers,
**When** When inspection runs,
**Then** Then the corresponding families and versions are identified reliably.

### FR-004-SC02: Allow future versions

**Given** Given a well-formed .NETCoreApp moniker with a future major version,
**When** When inspection runs,
**Then** Then it remains reportable without requiring a hard-coded version allowlist.
