# FR-006: Single-file inspect command

**Specification status:** Proposed
**Priority:** Must
**Original README reference:** REQ-006
**Source:** [Functional requirements](../../requirements/functional.md)

## Purpose

Expose dotnet framework inspect <path> and an actionable exit/status contract.

## Boundaries

This requirement does not authorize implementing dependent features early. Keep the declared framework distinct from SDK and executing runtime identity.

## Acceptance scenarios

### FR-006-SC01: Inspect a valid DLL

**Given** Given an existing readable DLL fixture with a declared target framework,
**When** When dotnet framework inspect is invoked with its path,
**Then** Then the command prints an accurate target-framework result and exits successfully.

### FR-006-SC02: Reject missing file

**Given** Given a path that does not exist,
**When** When inspect is invoked,
**Then** Then a useful error is emitted on stderr with a nonzero exit code.
