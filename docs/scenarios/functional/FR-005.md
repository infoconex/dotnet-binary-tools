# FR-005: Classify absent or unreadable targets

**Specification status:** Proposed
**Priority:** Must
**Source:** [Functional requirements](../../requirements/functional.md)

## Purpose

Distinguish unknown targets, non-managed inputs, and invalid/unreadable inputs.

## Boundaries

This requirement does not authorize implementing dependent features early. Keep the declared framework distinct from SDK and executing runtime identity.

## Acceptance scenarios

### FR-005-SC01: Unknown is not CLR metadata version

**Given** Given a legacy managed assembly without a target attribute and CLR metadata v4.0.30319,
**When** When inspected,
**Then** Then the target is unknown and is not reported as .NET Framework 4.0.

### FR-005-SC02: Corrupt metadata has distinct status

**Given** Given an invalid or truncated candidate assembly,
**When** When inspected,
**Then** Then inspection returns a classified invalid or unreadable outcome without fabricating a framework.
