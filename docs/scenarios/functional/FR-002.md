# FR-002: Read declared target-framework metadata

**Specification status:** Proposed
**Priority:** Must
**Original README reference:** REQ-002
**Source:** [Functional requirements](../../requirements/functional.md)

## Purpose

Read the TargetFrameworkAttribute using metadata APIs, not runtime assembly loading.

## Boundaries

This requirement does not authorize implementing dependent features early. Keep the declared framework distinct from SDK and executing runtime identity.

## Acceptance scenarios

### FR-002-SC01: Read a declared framework

**Given** Given a managed assembly carrying an assembly-level TargetFrameworkAttribute,
**When** When metadata inspection occurs,
**Then** Then the declared framework moniker is returned exactly as encoded.

### FR-002-SC02: Handle absent attribute

**Given** Given a managed assembly without TargetFrameworkAttribute,
**When** When metadata inspection occurs,
**Then** Then the declared target is unknown and no metadata inference is presented as fact.
