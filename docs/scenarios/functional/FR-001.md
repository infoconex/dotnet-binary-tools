# FR-001: Detect managed assemblies

> **Retired draft:** Predates the approved [CAP-001–CAP-008 model](../../capabilities.md); not an active requirement. Historical IDs are reserved and never recycled.

**Specification status:** Superseded historical draft; not active acceptance criteria
**Priority:** Must
**Source:** [Functional requirements](../../requirements/functional.md)

## Purpose

Inspect a DLL/EXE and determine whether it is a readable managed assembly.

## Boundaries

This requirement does not authorize implementing dependent features early. Keep the declared framework distinct from SDK and executing runtime identity.

## Acceptance scenarios

### FR-001-SC01: Recognize a managed library

**Given** Given a valid synthetic managed DLL,
**When** When the file is inspected,
**Then** Then the result identifies a readable managed assembly without executing it.

### FR-001-SC02: Reject a native binary as managed

**Given** Given a native PE executable with no CLI metadata,
**When** When inspection is attempted,
**Then** Then the result classifies it as not managed, without guessing a target framework.
