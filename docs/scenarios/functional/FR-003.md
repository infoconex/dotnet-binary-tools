# FR-003: Preserve and display target monikers

> **Retired draft:** Predates the approved [CAP-001–CAP-008 model](../../capabilities.md); not an active requirement. Historical IDs are reserved and never recycled.

**Specification status:** Superseded historical draft; not active acceptance criteria
**Priority:** Must
**Source:** [Functional requirements](../../requirements/functional.md)

## Purpose

Preserve raw target-framework monikers and provide a reliable human-readable name.

## Boundaries

This requirement does not authorize implementing dependent features early. Keep the declared framework distinct from SDK and executing runtime identity.

## Acceptance scenarios

### FR-003-SC01: Preserve the original moniker

**Given** Given a managed assembly declaring .NETFramework,Version=v4.8,
**When** When the target framework is reported,
**Then** Then the original string is preserved and the display name is .NET Framework 4.8.

### FR-003-SC02: Handle unrecognized moniker

**Given** Given a syntactically valid but unrecognized framework identifier,
**When** When the target framework is reported,
**Then** Then the raw moniker remains intact and the display name is not invented.
