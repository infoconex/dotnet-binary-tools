# FR-007: Directory scans

**Specification status:** Proposed
**Priority:** Must
**Source:** [Functional requirements](../../requirements/functional.md)

## Purpose

Scan candidate DLL/EXE files, optionally recursively, while isolating per-file outcomes.

## Boundaries

This requirement does not authorize implementing dependent features early. Keep the declared framework distinct from SDK and executing runtime identity.

## Acceptance scenarios

### FR-007-SC01: Inventory mixed candidates

**Given** Given a directory of valid managed, native and malformed DLL/EXE files,
**When** When scan is invoked,
**Then** Then each candidate receives an individual report without aborting on one failure.

### FR-007-SC02: Bound recursion and symlink traversal

**Given** Given recursive directories containing a symbolic-link cycle,
**When** When scan --recursive runs,
**Then** Then traversal terminates without following the cycle or processing the same directory indefinitely.
